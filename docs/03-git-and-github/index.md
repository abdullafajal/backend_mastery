# Module 3: Git and GitHub

Bazaar's code has lived in one folder on one laptop. One spilled cup of chai, and it's gone. A second developer joins, and nobody knows who changed what.
In this module, Bazaar's code gets a full history with Git, a home on GitHub, and a safe way for two people to work on it at the same time.
Every lab runs Git inside a container, so your own setup stays untouched.

1. [Commits and history](01-commits-and-history.md)
2. [Branches](02-branches.md)

4. [Rebase](04-rebase.md)
5. [GitHub and pull requests](05-github-and-pull-requests.md)
