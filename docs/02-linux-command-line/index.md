# Module 2: Linux and the command line

Bazaar's server has no screen. Everything happens in a terminal, often over SSH, often at 2 a.m.
In this module you become fluent: the shell, files, users and permissions, pipes, environment variables,
packages, SSH, services and logs. Every lab runs on a pretend Bazaar server in a container, so you can't break anything for good.

5. [Environment variables, packages and background jobs](05-env-packages-jobs.md)
6. [SSH](06-ssh.md)
