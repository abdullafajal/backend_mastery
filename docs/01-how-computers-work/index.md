# Module 1: How computers work

Every backend runs on a real computer. In this module, you open the box:
where data lives, how programs share one CPU, and what a "server" really is.

**Lessons**

1. [CPU, RAM and disk](01-cpu-ram-and-disk.md)
2. [Processes and threads](02-processes-and-threads.md)
3. [Memory: stack and heap](03-stack-and-heap.md)
4. [File systems](04-file-systems.md)
5. [What a server really is](05-what-a-server-is.md)

**Labs:** race RAM against the disk and the network; watch, signal and kill processes with `ps` and `top`; grow a memory leak until the OOM killer stops it; crash in the middle of a save; and build a web server from raw sockets.
