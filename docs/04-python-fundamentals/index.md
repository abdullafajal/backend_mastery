# Module 4: Python fundamentals

Bazaar's code so far is a few small files. To grow into a real shop (carts, orders, sellers), it needs clean, solid Python.
In this module you learn the language from the ground up, always on Bazaar's data: products, prices in paise, carts and invoices.
By the end, you build **Bazaar v0**: a command-line product catalog where you can add, list and search products.

Every lab runs Python 3.13 in a container. The lab folder is shared with your computer, so you write code in VS Code and run it there.
