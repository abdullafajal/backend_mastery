# Module 5: Advanced Python

Bazaar v0 works, but its products are plain dicts that accept anything, its code waits for one thing at a time, and it can't be installed anywhere else.
In this module, Bazaar's Python grows up: classes that guard their own data, decorators and generators, type hints, proper packaging,
and doing many things at once. It ends with the plan's lab: fetching prices from 100 supplier APIs three ways, and timing each.

Every lab runs Python 3.13 in a container, with the lab folder shared so you edit in VS Code.

4. [Decorators](04-decorators.md)
