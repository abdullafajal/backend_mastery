# Module 6: Data structures and algorithms for backend

Bazaar's code worked with 5 products. With a million, some pages take seconds, and the cause is almost never "Python is slow":
it's an algorithm doing far more work than it needs to. This module gives you the words for that (Big-O) and the data structures every backend is built on,
each with its real job: hash maps for caches, B-trees for database indexes, queues for background jobs, heaps for "what expires next", graphs for delivery routes.
It ends with the plan's lab: Bazaar's in-memory shopping cart store, with expiry.
